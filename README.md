### Challenges and Future Improvements

**What was hardest?**

The most challenging part of this project was configuring Docker and Docker Compose to run multiple services together, including FastAPI, PostgreSQL, Redis, and Celery. Managing environment variables, database connections, service dependencies, and container networking required careful debugging.

**What would I improve with more time?**

I would implement a complete CI/CD pipeline using GitHub Actions to automatically run tests, check code quality, build Docker images, and deploy the application. I would also improve Docker Compose configuration to make deployment and environment management more reliable.
